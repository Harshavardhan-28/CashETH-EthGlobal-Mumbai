# Test mocks

Local stand-ins used only by Foundry tests; none of them is deployed.

- `MockUSDC.sol`: permissive 6-decimal USDC with open `mint`. Its HTS facade is a no-op: `associate()` returns 22 (SUCCESS) and `isAssociated()` returns true. Use it for protocol tests (facility, routers).
- `MockHtsUsdc.sol`: USDC that enforces HTS association. Transfers to an account that has not called `associate()` revert, and `associate()`'s response code is configurable. Use it when the test is about association itself (spikes, `AssocProbe`).
- `MockHSS.sol`: the Hedera Schedule Service at `0x16b`. Install it with `vm.etch(address(0x16b), address(new MockHSS()).code)`. `scheduleCall` records the call and returns `(22, address(n))`. `deleteSchedule` marks a schedule deleted. `fire(schedule)` runs one pending schedule as its scheduler, forwarding `value` from the scheduler, and `fireAll()` runs every pending schedule. Neither checks `expirySecond`, so warp first if the target checks time. Response codes and capacity can be overridden for failure tests.
- `MockSwapRouter.sol`: stand-in for the Aqua SwapVM router on the facility's RCN to USDC fills, at a 1:1 price. `swap` reads tokenIn and tokenOut from the order (build it with `MakerTraitsLib.build`) and the taker's `isAToB` flag. It reads `(id, advanceBps)` from the taker data's instruction args, pulls `amount` RCN from the caller to `order.maker`, and pays `amount` USDC from its own balance, which you top up with `fund(usdc, amount)`. Then it calls `onCreditFill(id, order.maker, amount, aprOf[order.maker])` on the caller. Set a maker's APR with `setAprBps(maker, bps)`. While `fail(true)` is set, every swap reverts `MockSwapFailed()`. To make only a later fill fail, fund the router with less USDC than the fills need. For reconciliation tests, `setPayAdjust(d)` pays `amount + d` USDC, `setReportAdjust(d)` reports `usdcIn = amount + d` to `onCreditFill`, and `setReportedMaker(m)` reports `m` as the maker (zero restores `order.maker`).
